# PhpTutor Agent — контекст проекта

Локальный CLI-агент (PHP + Neuron AI + Ollama), который подключается к любому
проекту с уроками и ведёт персональный чат-тьютор по каждому уроку отдельно.

Агент **не привязан** к конкретному курсу: он ищет уроки в текущей рабочей
папке по контракту формата (см. ниже). Прогресс ученика хранится в папке
агента (`progress.json`), а не в проекте с уроками.

## Типовой сценарий использования

```bash
# 1. Запускаем проект с уроками (пример: php-guru)
cd C:\Users\dipan\OneDrive\Desktop\php\php-guru
npm run dev          # webpack dev-server на :8080, уроки в браузере

# 2. В любой момент, из той же папки, подключаем тьютора
php C:\dev\php-tutor-agent\chat.php            # меню выбора урока
php C:\dev\php-tutor-agent\chat.php 42         # сразу урок 42
php C:\dev\php-tutor-agent\chat.php --lessons=D:\other-course\lessons
```

Приоритет определения папки уроков:
1. `--lessons=<путь>` (аргумент CLI)
2. переменная окружения `PHP_TUTOR_LESSONS`
3. автодетект в текущей папке: `src/lessons` → `lessons` → `dist/lessons`
4. `lessons_path` из `config.json` рядом с агентом (запасной дефолт)

## Контракт формата курса — course-format v1

Агент считает папкой уроков каталог, в котором лежат подпапки с числовыми
именами (`01`, `02`, … `447`, …). Ведущие нули допустимы, сортировка числовая.

### `<lessons>/NN/lesson.json` (обязателен)

```json
{
  "number": 1,                          // int, совпадает с номером папки
  "title": "Введение в язык PHP",        // string
  "topic": "Основы",                     // string, тема-группа для меню
  "inTopicNumber": 1,                    // int, порядок внутри темы (необяз.)
  "url": "https://code.mu/ru/php/...",   // string, источник (необяз.)
  "contentHTML": "<p>...</p>"            // string, текст урока в HTML
}
```

- Обязательные поля: `number`, `title`, `contentHTML`.
- `topic` при отсутствии трактуется как `"Без темы"`.
- `contentHTML` перед попаданием в промпт очищается: содержимое
  `<pre>/<code>` сохраняется как блоки кода, остальные теги удаляются,
  HTML-сущности декодируются.

### `<lessons>/NN/notes.md` (опционален)

Заметки ученика по уроку. Если файл есть и не пуст — целиком добавляется
в контекст тьютора.

### `<lessons>/_index.json` (опционален, игнорируется агентом)

Агрегированный индекс (в php-guru его генерирует `scripts/generate-index.js`
в `dist/lessons/`). Агент читает уроки напрямую из папок `NN/`, чтобы не
зависеть от свежести сборки.

## Версионирование контракта

- **course-format v1** (2026-11-13) — текущая версия. Структура `NN/lesson.json` + `notes.md`.
- При изменении формата в проекте с уроками (новые поля, другая структура
  папок): создать `course-format v2` в этом файле, обновить `CourseLoader`
  (он обязан принимать обе версии или явно ругаться на неподдерживаемую).

## Особенности локальной модели (Ollama, php-tutor-qwen)

Модель `php-tutor-qwen` — это `qwen3:4b` (Q4_K_M) с параметрами
temperature 0.6, top_p 0.95, top_k 20, num_ctx 4096. Важные факты,
проверенные экспериментально (2026-11-13):

- **Эта сборка qwen3 всегда рассуждает.** `think:false` НЕ отключает
  рассуждения, а лишь выводит их в `content` вместо `thinking`.
  Поэтому параметр `think` из агента не передаём: при поведении по
  умолчанию рассуждения уходят в поле `thinking`, а в `content`
  приходит короткий готовый ответ (его и читает Neuron AI).
- **На CPU ответ занимает 1–3 минуты** (рассуждения ~500–1000 токенов
  при ~10 ток/с). Таймаут поднимается в двух местах: `withTimeout(600)`
  в `PhpTutorAgent::provider()` (дефолт Neuron — 60 с) и
  `ini_set('default_socket_timeout', '600')` в `chat.php` (в системе
  нет php.ini, и дефолтный сокетный таймаут PHP-обёртки 60 с убивает
  запрос независимо от настроек Guzzle — нужны ОБЕ правки).
- Если ответы слишком медленные — правильное решение: сменить модель
  на instruct без thinking (например, qwen2.5:3b-instruct) и
  прописать её имя в `config.json` → `model`.
- Шаблон модели (Modelfile template) сохранён в
  `samples/qwen3-template-old.txt` — он рабочий, не менять на
  «no-think» вариант: с жёстко закрытым `<think></think>` эта сборка
  всё равно рассуждает, но уже в `content`.
- **В winget-PHP не было php.ini** — создан рядом с php.exe
  (`...\PHP.PHP.8.4_...\php.ini`): включены curl, mbstring, openssl,
  `default_socket_timeout = 600`. Без curl Guzzle работает через
  fopen-обёртку, которая рвёт запрос на 60-й секунде независимо от
  настроек клиента. PHP не в PATH — полный путь к php.exe в этом
  ini-файле; `npm run tutor` в php-guru рассчитан на `php` из PATH
  (каталог winget-пакета уже в пользовательском PATH).
- **На машине ДВА PHP.** В обычном PATH — winget PHP 8.4
  (`...\WinGet\Packages\PHP.PHP.8.4_...\php.exe`, для него создан php.ini
  с curl/mbstring/timeout 600). В терминале VS Code `php` резолвится в
  npm-пакет php-composer-cli (PHP 8.5.9, без curl и mbstring) — под ним
  агент умирает на 60-й секунде. Поэтому `npm run tutor` в php-guru
  вызывает winget-PHP по ПОЛНОМУ пути, не через PATH (коммит 6805139).
- При тестах curl из Git Bash на Windows кириллица в `-d` ломается
  (модель получает mojibake и «залипает» на разборе кодировки).
  Для тестов отправлять JSON через Python/PHP, не через curl -d.

## Архитектура агента

| Файл | Назначение |
|---|---|
| `chat.php` | Точка входа: меню уроков, цикл чата, запись прогресса |
| `src/PhpTutorAgent.php` | Агент Neuron AI: провайдер Ollama, системный промпт с контекстом урока и прогрессом |
| `src/CourseLoader.php` | Автодетект папки уроков, парсинг `lesson.json`/`notes.md`, очистка HTML |
| `config.json` | Дефолты: модель/URL Ollama, запасной `lessons_path` |
| `progress.json` | Общий прогресс ученика (уровень, слабые темы, пройденные уроки) |
| `CONTEXT.md` | Этот файл — контракт и контекст проекта |
| `samples/` | Образцы уроков из php-guru для разработки и тестов |
